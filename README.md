# 📍 KOALA - 한국항공대학교 알고리즘 학회 웹 서비스

## 💡 서비스 소개
한국항공대학교 알고리즘 학회 KOALA(**KO**rea aerospace university **AL**gorithm **A**ssociation)를 위한 웹 서비스입니다.

---

## 🌠 프로젝트 배경
기존 스터디 운영 과정에서 운영진과 스터디원 측면의 문제점은 아래와 같습니다.

- 운영진 문제점 : **과도한 단순 반복 업무**
  - 주 1회 문제집 제작, 주 1회 출석부 갱신, 연 4회 지원서 제작, 모집 전형별 결과 통보 등

- 스터디원 문제점 : **분산된 플랫폼, 코딩테스트 관련 정보 부족**
  - 구글폼, 슬랙, 카카오톡, 노션 등 분산된 플랫폼으로 인한 혼동
  - 운영진의 단순 반복 업무로 인한 코딩테스트 정보 준비의 어려움

이에 기존 **학회 운영에 필요한 모든 과정을 하나의 플랫폼으로 통일하고, 단순 반복 업무 자동화를 통한 자료의 질적 향상을 달성**하고자 했습니다.
